A crash-safe, append-only log of what is being attempted on the Alta. Every risky step writes a
`STARTING` line **before** it begins, then a `DONE` or `FAILED` line when it ends. `scripts/progress`
forces each line to disk, so it survives a power cut that comes right after it.

**How to resume:** read the log below from the end.
- `boot=` is the first 8 characters of the boot ID (`cut -c1-8 /proc/sys/kernel/random/boot_id`). If it
  differs from the current boot ID, the board has rebooted since that line was written.
- A `STARTING` line with no `DONE`/`FAILED` after it is the step that was running when the board died.
  If it was an NPU attempt, treat it as an incident (handoff R5). Do no more NPU work. Collect the
  evidence (the line names its capture directory), record it, set `runs/STOP` and report to Jordan.
